# Emotion Character Images

Thư mục này chứa hình ảnh của 4 nhân vật từ phim "Inside Out" đại diện cho các cảm xúc:

## Cần thêm các file sau:

1. **joy.png** - Nhân vật Joy (Vui vẻ) - màu vàng
2. **fear.png** - Nhân vật Fear (Sợ hãi/Trung tính) - màu tím
3. **sadness.png** - Nhân vật Sadness (Buồn) - màu xanh dương
4. **anger.png** - Nhân vật Anger (Tức giận) - màu đỏ

## Kích thước đề xuất:
- 512x512 pixels hoặc lớn hơn
- Format: PNG với nền trong suốt
- Chất lượng cao để hiển thị rõ nét

## Nguồn hình ảnh:
Bạn có thể tìm hình ảnh từ:
- Google Images: "Inside Out characters PNG"
- Official Disney/Pixar resources
- Fan art (đảm bảo có quyền sử dụng)

## Lưu ý bản quyền:
Hình ảnh nhân vật Inside Out thuộc bản quyền của Disney/Pixar. 
Chỉ sử dụng cho mục đích cá nhân/học tập.
